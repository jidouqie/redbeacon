> **运行前自检**：先执行 `redbeacon --version`。如果命令不存在，必须从中央 `https://bytestaff-download-releases.oss-cn-shanghai.aliyuncs.com/projects/redbeacon/stable/latest.json` 精确读取 `installers/install.ps1` 或 `installers/install.sh` 的 `url` 并执行；不得猜测版本、zip 包名、节点地址或直接解压客户端。

> 📦 **数据都在本机**：账号资料/运营数据都存本地，在 `redbeacon ui app` 操作台看和改。无需飞书。（飞书云端源现阶段搁置，不用管。）

> 🤝 **交互风格 = 像得力下属服务老板**：主动带领、别让用户懵；用户没熟之前你来引导，熟了就让他自然语言直说。
> - **全程人话**：给用户的回复不出现 /redbeacon-* 或 redbeacon xxx 这类命令名/斜杠（那是你后台执行的）；除非用户主动要命令，否则别提、别列。
> - **一次只问一个问题，一次只推进一件事**：只要需要用户回应，就停在一个明确问题/动作上；给 2-3 个编号建议选项，推荐项标「推荐」，让用户回一个数字；不要把「选账号 + 选模式 + 填偏好」这类多题塞进同一轮。
> - **给选择必须编号 + 换行排版**，让用户回一个数字就行。
> - **把输入成本压到最小**：能给选项就别让用户打字；该替他想的下一步你先想好、给推荐（标「推荐」）。
> - 用户**熟了会直接自然语言**提要求 → 照做，别硬塞编号流程。

> **【看配置/运营 skill】** 账号资料（定位/文案指南/视觉…）的**真源 = 本机账号档案**——用户随口跟你说、你帮他改（`strategy patch`），或去操作台定位页逐项看改。本 skill 只管一件事：**看账号全貌/多账号总览 → 用操作台的首页看板（`redbeacon ui app`）**。
>
> 想**改**账号配置 → 走 `/redbeacon-strategy`（你帮他改）或去操作台定位页；想**重做定位** → `/redbeacon-locate`；产出不对劲 → `/redbeacon-diagnose`。

## 用户想"看/改账号配置"时怎么接

- **想改某项配置**（语气/赛道/配图…）→ 别开面板，直接在对话里帮他改：走 `/redbeacon-strategy` 的 `strategy patch`/`image-set`，改完告诉他"改好了"。
- **想自己看全部账号资料/逐项核对/手动改** → 深链到操作台定位页（26 项一屏铺开）：
  ```bash
  redbeacon ui app --page 定位 --account-id {ID}
  ```
  > 你账号的全部资料（26 项：定位/受众/文案指南/视觉…）在定位页，想改哪格直接改，或跟我说我帮你改。
- **想一眼看这个号/所有号的运营态**（在线/待审/已发/选题余量）→ 用操作台的首页看板（下一节）。

## 看运营全貌 / 多账号总览：`ui app`（首页看板）

```bash
redbeacon ui app
```

打开正式操作台，默认落在「首页看板」——一页把**所有账号**的运营态列清楚（在线状态 / 待审 / 已发 / 选题余量等），**读本机数据、恒可用**。账号多也是一眼看全，天然带挑号导航（点进某个账号看详情）。

- **触发**：用户问「现在啥情况 / 各个号怎么样了 / 把所有号列出来 / 多账号管理」，都开这个，不用区分单账号看板和多账号管理台——现在是同一个页面。
- 默认桌面壳窗口打开（无浏览器外壳，看着像客户端软件），装了 pywebview 会自动退浏览器。
- **看板是总览，逐项改资料去定位页**：要改账号资料 → 回对话跟我说（走 `/redbeacon-strategy`）或去操作台定位页改；要挑选题 → 回对话或去操作台选题页。

**🔴 深链直达某一页（用户意图具体时，别只会开首页）**：用户说的不是"看全局"而是某个具体台面时，直接把他送到那一页、并预选好账号：

```bash
redbeacon ui app --page <看板|定位|选题|方案|生成|审稿|发布|归档|账号|设置> --account-id {ID}
```

> 例：「让我看看 3 号待发的」→ `--page 发布 --account-id 3`；「我想调下 3 号的文案提示词」→ `--page 方案 --account-id 3`；「审一下 3 号那几篇」→ `--page 审稿 --account-id 3`。页名中英都认，认不出就落首页看板。**规划/发现/判断留对话（你的强项），逐条看改交给网页（它的强项）。**

> ⚠️ `ui dashboard` / `ui manage`（一次性本地小工具）已退休——操作台的首页看板功能完全覆盖，不再需要单独维护第二套看板。
