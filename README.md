# RedBeacon · 小红书运营数字员工

RedBeacon 是一款面向小红书运营的本机数字员工。它把账号定位、选题规划、文案与封面生成、本机审稿和发布串成一条可见、可控的工作流，让创作者把时间放在方向和判断上。

[产品主页](https://bytestaff.jiomig.com/market/redbeacon)

## 能做什么

- **多账号管理与扫码登录**：在一台电脑上管理多个小红书账号，账号资料、内容和登录态按账号隔离。
- **对标账号学习**：粘贴小红书账号主页，RedBeacon 学习其定位逻辑、内容节奏、文案方法和视觉语言，再生成适合当前账号的方案。
- **单篇笔记风格学习**：粘贴一篇喜欢的笔记，提炼标题、正文和封面方法，沉淀为可长期复用的内容方案。
- **选题、文案与封面**：围绕账号定位生成选题和笔记，支持 AI 封面、文字卡片以及组合配图。
- **本机审核与发布**：成稿进入本机审稿台，修改、通过后再发布；不会未经确认自动发出内容。
- **AI 助手协作**：支持 Claude Code、Codex、OpenClaw、Hermes 和腾讯 WorkBuddy，也可以完全通过桌面客户端使用。

业务数据默认保存在本机。ByteStaff 平台仅提供账号身份和 AI 能力，不保存你的本地运营资料。

## 安装正式版

安装入口长期不变，会自动选择当前正式版本，并校验版本、文件大小和 SHA-256。

### macOS（Apple Silicon）

在“终端”中运行：

```bash
curl -fsSL https://bytestaff.jiomig.com/redbeacon/install.sh | bash
```

### Windows 10 / 11

在 PowerShell 中运行：

```powershell
irm https://bytestaff.jiomig.com/redbeacon/install.ps1 | iex
```

安装完成后，RedBeacon 会自动启动。以后从客户端设置页、CLI 或 AI 助手触发升级，都会执行同一套全量更新流程。

## 使用流程

```text
安装 / 更新 → 平台登录 → 创建账号 → 小红书扫码登录
→ 定位 / 选题 → 生成 → 本机审核 → 发布
```

生成与发布都是用户主动触发的前台操作。RedBeacon 不依赖后台常驻服务，也不会绕过审稿状态偷偷发布。
