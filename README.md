# RedBeacon · 小红书 AI 内容运营

> 让创作者专注**策略**，把选题、写文案、做图、排版、发布这些**脏活累活交给 AI**。

RedBeacon 把"运营一个（或一批）小红书账号"拆成一条清晰的流水线，每一步都由你的**个人 AI 助手**驱动——你只用大白话说要干什么，背后自动完成。

---

## 设计理念

- **你定方向，AI 干活。** 你负责"这个号做什么、给谁看、什么调性"；选题枯竭了自动补、文案自动写、配图自动出、发布自动排——重复劳动不该耗你的精力。
- **审核在你手里，不在黑箱里。** 所有生成的内容进**飞书多维表格**，你在飞书里改稿、定稿、标「通过」。标了通过的才会被发出去，没有任何"本地偷偷审核"的逻辑。
- **一个号免费，多个号矩阵化。** 单账号永久免费；要同时运营多个号（矩阵、防关联、批量发布）再解锁。
- **你不用懂技术。** 你只跟 AI 助手对话，不用管背后是命令行还是别的。装一次、说人话、看结果。

---

## 能做什么

装好后，在你的 AI 助手里输入 `/redbeacon` 进入，它会判断你到哪一步、把你带到该用的能力：

| 你想干的 | 对 AI 助手说 |
|---|---|
| 配置（AI / 飞书 / 代理） | "配置 RedBeacon" |
| 加账号 / 多账号解锁 | "加一个账号" |
| 给账号做定位、出选题 | "给这个号定位" |
| 调文案风格 / 配图方式 | "改一下文案风格" |
| 生成内容 | "生成几篇笔记" |
| 审核改稿 | 在**飞书表格**里改、标「通过」 |
| 发布已通过内容 | "把通过的发出去" |
| 看整体运营情况 | "各个号现在怎么样了" |
| 产出不对劲找原因 | "最近文案有点跑题" |

完整链路：**配置 → 建账号 → 定位 → 登录 → 绑飞书 → 生成 →（飞书里审核）→ 发布**。全程手动触发、无后台常驻服务。

## 安装

零环境的电脑也能装。对你的个人 AI 助手说一句"帮我装 RedBeacon"，让它执行：

```bash
curl -fsSL https://redbeacon.jiomig.com/install.sh | bash
```

脚本会自动：装好运行时（自带 Python，无需预装）→ 装 RedBeacon → 下载所需浏览器内核 → 把 skill 安装进你的 AI 助手。装完对 AI 助手说 `/redbeacon` 即可开始。

> 升级：以后对 AI 助手说"升级 RedBeacon"，它会把 CLI 和 skill 一起更新到最新。

## 这个仓库里有什么

本仓库是 RedBeacon 的**开源部分**：

```
.claude/commands/   # skill —— 驱动整个产品的命令（开源，纯指令/流程，无商业机密）
install/install.sh  # 一键安装脚本
tools/gen_latest.py # 版本清单生成器
latest.json         # 版本清单（升级检查用）
```

**驱动 skill 的 CLI 引擎是闭源的**，以打包好的形式分发（安装脚本会自动拉取），不在本仓库开源。RedBeacon 对个人创作者**单账号免费**；多账号矩阵能力需购买解锁。
