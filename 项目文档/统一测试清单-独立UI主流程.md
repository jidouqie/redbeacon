# 统一测试清单 · 独立 UI 主流程（给老板照着走）

> 编写：2026-06-28 · PM 窗口。范围 = 独立 UI 四刀（看板/选题/生成/审稿/发布）+ 前序未测的客户端重构。
> 目的：把"离线全绿但真接口没连过"的缺口在你这台有凭据的机器上一次补齐。
> 出任何问题：记下来（哪一步、点了啥、看到啥、期望啥）→ 贴回给我 → 我转开发修 → 修完我对账。

## 0. 开测前准备
- **机器要满足**：① 飞书 app_secret 能解密；② 已登数字员工平台（有设备令牌）；③ 已登一个**小红书测试号**（⚠️ 别用主号，有封号风险）。
- **代码就位**：四刀改动还没提交，确认你测的就是这份工作区代码。
- **测试数据隔离**：用测试飞书 Base + `REDBEACON_DATA_DIR=/tmp/rb_e2e`（别污染真账号库）。
- **起界面**：双击 `install/launchers/` 启动器（Mac `.command` / Win `.bat`），或命令行 `redbeacon ui app` → 浏览器开 localhost。

## 1. 冒烟（先确认没塌，再细测）
- [ ] `redbeacon --version` 出版本号。
- [ ] 全套离线测：`cd cli && python -m pytest -q` → 期望 **107 passed**。
- [ ] 界面能打开，首页看板加载不报错。

## 2. 登录 / 配置（前序重构 + UI 外壳）
- [ ] **平台登录**（device flow）：UI 触发 → 显示授权码 + 短链 → 浏览器授权 → 回到 UI 显示"已登录"+点数。期望：点数照实显示 checkin 的 remaining。
- [ ] **飞书绑表**：配飞书 → 自动复制模板 Base 到你租户 → 绑定成功。期望：看板能读到该号四表数据。
- [ ] **小红书登录**：扫码登录测试号 → UI 顶部登录灯变"在线"。
- [ ] **去掉旧解锁码确认**：不再要求任何激活码/解锁码即可使用。

## 3. 主干闭环（核心，按顺序走一遍）
### 3.1 选题
- [ ] 灵感箱 / 选题盘面两面板能看到飞书选题表数据（读不到应显"暂不可用"，不是报错崩）。
- [ ] **AI 补题**：选条数+应用域 → AI 铺一批候选 → 编号列出 → 勾选入库。期望：① 扣点（文案 1 点/次，点数减少）；② 入库的候选**落在灵感箱（阶段=灵感），不是直接变选题**。
- [ ] **灵感→选题**：在灵感箱点"转为选题" → 去飞书看该行**阶段真的变成「选题」**。
- [ ] **改 brief**：改某条选题的角度/提纲/优先级 → 存 → 飞书该行真的改了。

### 3.2 生成（文案+图全走平台）
- [ ] 生成页挑一个题（或手填）→ 写文案 → 出封面 → 入飞书审核表。期望：
  - 文案是平台写的、**扣 1 点**；封面是平台生的、**扣 10 点**；点数照实减。
  - 生成成功后这条出现在**审稿页待审列表**里。
  - 选题→文案后，**原选题行从选题表消失**（被消费），brief 快照进了审核表那行。
- [ ] **失败分界验证**：故意把点数耗到不够 → 再生成 → 期望文案**硬停报"点数不足/去升级"，不写半截脏稿**；若只是图没出成 → 期望**文字稿照样入审核表 + 提示稍后补图**。

### 3.3 审稿（飞书读改写回）
- [ ] 审稿页列出"未审核"记录 → 改标题/正文/标签 → 通过/驳回/存 → **飞书该行真的改了状态**。
- [ ] **空正文不许通过**：清空正文点通过 → 期望被拦。
- [ ] **多窗口对账**：在飞书手机端/网页改同一条 → UI 刷新看到一致（证明无本地副本、无双向同步漂移）。

### 3.4 发布（换 IP + 移归档）
- [ ] 发布页只列"已通过"的稿（草稿/驳回/未审核不出现）。
- [ ] 掉线测试：退出小红书登录 → 发布按钮**置灰禁用**+提示去登录。
- [ ] 正常发布：点发布 → （配了代理则先换 IP）→ 自动发到小红书测试号 → 期望：
  - 小红书真的出现这篇笔记。
  - **审核表该行消失、归档表新增一行**（移归档），回写笔记链接（链接可能为空=已知限制）。
  - **本地没有任何"已发布"标记**，一切以飞书为准。
- [ ] 失败重试：制造一次发布失败 → 审核表该行标"发布失败"+原因、留着可重试（不丢）。

## 4. 红线专项核对（边走边对，重点这几条）
- [ ] **数字对得上**：看板念的待审/选题余量/已发 = 飞书里真能看到的数；读不到飞书显"—"不糊弄。
- [ ] **飞书单一真源**：全程没在本地存第二份业务数据；UI/飞书/CLI 三个窗口看同一份、永远一致。
- [ ] **不持上游钥匙**：客户端只有设备令牌，没有任何上游 AI key。
- [ ] **扣点只发生在 AI**（文案/生图）；选题管理、审稿、发布**不扣点**。
- [ ] **换 IP 生效**（配了代理的话）：发布前 IP 变了。

## 5. 已知偏离（不是 bug，别误报）
- 笔记链接可能为空（小红书接口拿不到稳定笔记 ID，既有限制）。
- 批量改 brief 没做、选题的标签[多选]/对标截图[附件]只读不改（避免写坏飞书字段）。
- 流式打字机没做（生成是一次性出文案，非逐字蹦）。
- 图生图/参考图（人物一致）走的是普通文生图（平台该能力未上线）。
- "全部发布""定时排期"没做（本轮只手动发单条）。
