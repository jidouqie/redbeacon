# 0.1.129 安全依赖与发布恢复维护

本次维护更新适用安全依赖，并修复发布恢复、自动化撤权及客户端更新流程。公开安装入口字节、长期官网 URL、安装外层命令和通道边界保持不变。

## 主要变更

- Pillow 12.3.0 升至 13.0.0；图片净化、参考图、对标素材和共享卡片封面在插件探测前仅允许 JPEG、PNG、WEBP。
- certifi 更新至 2026.10.19，构建固定 uv 0.13.6 和 CPython 3.12.16；其他运行与开发依赖保持锁定。私有 CI 使用官方固定提交的 setup-uv，避免旧 Python/pip 引导信任链。
- 每账号、每稿件保存持久发布请求、明确成功回执与防重栅栏。重启恢复沿用原 request_id 补结算与归档，不再次提交浏览器或创建新预留。
- 归档、删除审稿行和发布日志标记同事务。数据库结构追加至 v4；备份格式 v7 保留发布事实及稿件编号高水位，继续接纳旧版备份。
- 无法取得可信成功回执的跨重启提交返回失败并保留内部防重栅栏，提示核实，不自动猜测或重发。
- 排队自动化只保留入队权限与最新权限的交集，并在实际浏览器发布点击前再次检查；撤权保留已生成或已通过稿件。
- 更新流程区分启动确认与安装完成；下载失败、空响应及失败的部分响应不再报告完成。外部安装器预检通过后负责停机，客户端不提前强退；界面持续持有更新/修复互斥至结果返回。

## 验证记录

维护阶段隔离回归：CLI 1477 项通过；公开工具 31 项及 91 个子测试通过。使用临时数据库、假浏览器及计费接口，没有真实发布或 AI 付费调用。

发布验收仅使用本机 macOS arm64 与现有 Windows 虚拟机 x64 Python，不使用 GitHub Actions 打包或验收。首轮本地验收发现更新器临时日志清理顺序及 Windows 测试适配问题，已补充关闭后清理回归、PowerShell 5.1/7.6 离线故障测试和 UTF-8 文件读取。更新器 macOS 定向回归 36 项通过；Windows 本地虚拟机定向回归 40 项通过、8 项平台专属跳过，其中 PowerShell 5.1/7.6 各 6 项原生离线故障测试全部通过。Unix 安装事务检查使用受控输出管道等待真实卸载 helper 被观测，避免短进程采样误阴性；保持公开入口及 helper 原字节、完整通道参数与严格辅助进程数量校验。

本版本精确提交的双平台全量回归、冻结包和安装事务验收将在完成后补记。当前尚未发布本版本，不代表用户已完成测试版手动试用。

## 兼容与发布条件

- 升级前数据库快照、隔离迁移演练与失败回滚继续沿用现有机制；未对真实用户数据库做测试迁移。
- 已迁移至数据库 v4 或新备份 v7 后，旧客户端必须拒绝不支持的数据格式；不能用旧包直接覆盖后继续写入。
- 跨重启结果未知且无可信对账接口时，需要人工核实；不会自动解除防重保护。
- 按项目规则先发布测试版，用户手动安装并确认通过后，再用同一代码构建正式版。
