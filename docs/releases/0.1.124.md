# 0.1.124 测试版更新说明

- 每篇发布方式与北京时间保存到本机业务库，切换账号、刷新或重开后保留；支持单篇保存与 UTF-8 JSON 批量保存，保存本身不会发布。
- 无效、缺失、过期或超出范围的定时时间在提交时自动转为立即发布；有效时间仍按原排期，页面明确显示实际方式。
- 修复小红书日期控件确认后恢复默认时间的问题，兼容两种定时开关结构，提交前核对实际值。
- 发布动作失败后自动重试 3 次，首次加重试最多 4 次；检查迟到的成功回执，重试使用同一笔预留。
- 单篇重试耗尽后保留原稿、通过状态与具体错误，批量继续下一篇；客户端显示成功、失败和未尝试数量。
- 修复发布按钮定位、原创声明状态识别和标题框被遮挡导致的操作异常，保留用户逐篇选择的发布选项。

客户端业务数据和账号仍保存在对应通道的本机目录。测试版与正式版保持隔离；本次不修改安装、更新入口和公开安装命令。安装后的完整客户端体验仍需人工验收，通过后再决定是否发布正式版。
