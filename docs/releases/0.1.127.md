# 0.1.127 PowerShell 安装兼容性验证

修复 PowerShell 7.5+ 把 .NET 环境变量删除调用中的 $null 转为空字符串，进而让 Playwright 使用空驱动路径的问题。正式和测试安装入口均修正清理与恢复行为；现有驱动配置机制、通道、安装命令与单进程安装方式保持原样。

## 实际安装对照

环境：Windows 11 ARM64 虚拟机，运行 x64 冻结客户端；PowerShell 7.6.0 与 Windows PowerShell 5.1。安装包与技能从本机隔离源提供，用户目录隔离；CLI、渲染器和浏览器均运行真实制品。冷启动场景沿已发布的浏览器下载地址获取并校验内核。
