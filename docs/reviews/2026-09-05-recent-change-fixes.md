# RedBeacon 审查问题修复记录（2026-09-05）

对应 [最近修改审查](2026-09-05-recent-change-audit.md) 中的 5 项功能问题与 1 项验证缺口。修复基于根仓 `701dbd9`、CLI 子仓 `c581bc2` 及开始修复时已有的未提交改动。四个安装入口仅补回滚状态与 Windows 中文路径启动器，保留原有单进程安装策略、固定通道、官网 URL 和外层命令。

## 已修复行为

1. **发布结果待确认**：只有明确 `confirmed=True` 才按成功结算并归档。缺失回执、点击后异常、浏览器工作线程超时均进入待确认；取消预留、不成功结算、不归档、不删稿、不自动重试。稿件回到未审核并保留警告，重新通过前 UI 提醒先核查小红书。客户端单篇、批量、自动化、CLI、代理工作进程均传递这一状态；批量停止后续项并保留浏览器核查窗口，释放执行锁。
2. **发布按钮重复点击**：原“等待按钮”函数内部实际执行点击，并可能吞掉点击超时继续尝试。现在等待阶段只返回按钮，提交阶段点击一次；新版组件按钮与旧版按钮均有回归覆盖。
3. **macOS 失败回滚**：分别记录旧应用已备份、新应用开始放置。旧应用备份失败时保持旧应用原样；放置或后验失败时删除新应用并恢复旧应用。恢复失败时保留备份并提示位置。
4. **Windows 中文用户路径**：`.cmd` 保持 ASCII，运行时展开 `%LOCALAPPDATA%`，避免中文用户名在写文件时变成问号。健康最新版重复安装也刷新启动器，修复旧的损坏入口；参数和退出码继续透传。
5. **页面重新载入**：首次认证后设置仅用于根页面的 HttpOnly、SameSite=Strict 会话 Cookie；刷新响应注入当前实例口令，前端可继续调用 API。API 仍要求显式口令。正式/测试窗口 Cookie 名按实例区分，响应禁止缓存，缓存模板不包含用户口令。
6. **RedNote 实时登录核验**：先检查导航、HTTP 状态、官方域名和安全验证页，再接受已认证页面标记。`id_token` 只触发同一浏览器上下文内的临时创作者页核验，不能直接证明在线。扫码/手机号登录保留取消与会话代次检查，取消后不保存登录 Cookie。
7. **安装验收证据**：两平台报告实际写入事务、跨通道目录、调用者环境与进程观察结果；汇总器逐项验证后生成覆盖范围，制品检查再次验证原始报告。缺失/篡改证据、隐藏第二个 shell、进程观察失败均阻断。Windows 补齐临时包四种故障回滚和成功更新快照验证。
